#1 Crypto × ML

dInference

A permissionless Solana protocol for verifiable LLM inference. A 256-byte hidden-state fingerprint catches model substitution at 100% TPR / 0% FPR, about 18× faster than re-execution.

Python · Rust · PyTorch · Anchor · Solana

#2 Distributed systems

UtterDB

A sharded key-value store in Go: 100K+ req/s at 1ms p50. It has consistent hashing, replica failover, and zero-downtime rebalancing, and survived 150M Locust requests with zero failures.

Go · gRPC · Terraform · Locust

#3 Real-time data

Insider Flagger

Watches 1,000+ Polymarket markets live and scores traders whose wins are statistically hard to explain. Monte Carlo runs under Numba (3ms per wallet), feeding a Redis leaderboard.

Python · FastAPI · asyncio · Numba · Redis

#4 Forecasting

Kalshi Climate

An ensemble temperature forecaster for Kalshi’s daily-high markets. It fits a Gaussian KDE over multi-model forecasts and backtests against observed daily highs.

Python · OpenMeteo · SciPy · Streamlit

#5 Quant finance

Options Pricing

An options pricer in C++: Black–Scholes with historical volatility, plus Monte Carlo whose Wiener process samples any user-defined distribution via accept–reject sampling.

C++ · Matplot++ · cpr · nlohmann/json

#6 WebAssembly

WASM Analytics

A browser-only data-analytics tool: Python and Streamlit running on WebAssembly. Upload a CSV and run commands for smoothing, ACF/PACF, ARIMA, correlation, PCA, and more.

Python · Streamlit · stlite · Pyodide
